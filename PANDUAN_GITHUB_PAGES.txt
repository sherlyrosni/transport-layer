PANDUAN SINGKAT UPLOAD KE GITHUB PAGES

1. Buka https://github.com lalu login.
2. Klik New repository.
3. Nama: transport-layer-interaktif
4. Pilih Public.
5. Klik Create repository.
6. Klik Add file -> Upload files.
7. Upload:
   - index.html
   - styles.css
   - app.js
   - README.md
8. Klik Commit changes.
9. Buka Settings -> Pages.
10. Source: Deploy from a branch.
11. Branch: main.
12. Folder: /(root).
13. Klik Save.
14. Tunggu beberapa menit.
15. Buka URL GitHub Pages yang muncul.

Contoh:
https://USERNAME.github.io/transport-layer-interaktif/

Tidak perlu domain berbayar.
